============================================================
  CT缺陷检测系统 — 使用说明（便携版）
============================================================

本系统已做成便携版：无需安装 Python 或任何软件，
整个文件夹拷贝到任何 Windows 电脑（U盘/网盘/直接复制），双击即用。

  有独立显卡（较新型号）→ 自动用显卡，速度快
  老显卡或没有显卡      → 自动退回 CPU，功能不变只是慢一些

------------------------------------------------------------

根目录只有 3 个开关，要用哪个双击哪个：

  启动检测.bat     日常检测（浏览器自动打开 127.0.0.1:5000）
  开始训练.bat     训练新模型（有显卡自动用显卡加速）
  检查环境.bat     环境出问题时点它做体检

------------------------------------------------------------

【日常检测】
  双击 启动检测.bat → 等 10-20 秒 → 浏览器自动打开。
  停止服务: 关闭黑色窗口。

【训练新模型（支持多型号、多版本管理）】
  1. 双击 开始训练.bat
  2. 按提示选择数据集（输入编号）
  3. 给这次训练起个名字（如 A型号第一批），回车开始
  4. 训练完成后，新模型在 runs\detect\CT_pro\<你的名字>\weights\best.pt
     训练曲线和报告也在同一个文件夹里
  5. 确认效果满意后，把 best.pt 手动复制到 models\启用\
     （在 启用 下建子文件夹放，如 models\启用\A型号第一批best.pt，文件名保持 best.pt 不改）
  6. 重启 Web 端，网页模型列表里就能选用它

  注意：网页上能选的模型只来自 models\启用\ 文件夹。
  训练出的模型不会自动出现在网页上，必须经过你确认后手动放进去。

【搬到新电脑怎么用】
  整个「CT Detection」文件夹原样拷贝过去，双击 启动检测.bat 即可。
  注意必须整个文件夹一起拷，runtime 文件夹是运行环境，不能少。

【目录说明】
  runtime\    便携 Python 运行环境（勿动、勿删）
  web\        Web 检测系统主程序
  core\       全局配置(Config.py) + CT图像预处理
  scripts\    训练脚本、数据增强等工具
  models\启用\      网页可选模型（只放你确认可用的）
  models\pretrained\ 训练用的基础模型（勿动）
  datasets\   训练数据集
  runs\       训练记录（每次训练一个独立文件夹）
  docs\       文档
