## 二、#1 旋转：两个缺陷，不是一个

1. **方向反了**（原报告）：`M` 的线性部分是 `[[cos,sin],[-sin,cos]]`（视觉逆时针），而框侧手写
   `[[cos,-sin],[sin,cos]]`（反向）。距中心 640px、3° 时偏差 `2·640·sin3° ≈ 67px`。
2. **新发现：`BORDER_REFLECT` 会造出无标签的假缺陷**。实测 15° 时，画面右侧边缘出现一整条
   镜像白块（`pix bbox x_max=639`，而真实块只到 565）——训练时这就是"背景里的缺陷"，直接教模型忽略它。
   改为 `BORDER_REPLICATE`（只延展边缘像素，不复制内容）。

回归测试 `scripts/test_augment_rot.py`（纯黑图 + 偏心白块，从像素反算真实框比 IoU）：

| --- | --- | --- |
| -15° | 0.997 | 0.000 |
| -5° | 0.991 | 0.228 |
| -3° | 0.993 | 0.405 |
| +3° | 0.983 | 0.408 |
| +5° | 0.989 | 0.228 |
| +15° | 0.985 | 0.000 |

## 三、#3 + #6：状态与台账

**旧行为**（会出质量事故的两条）：

- 批量读图失败 `continue` 跳过 → `results` 少一项 → 前端 `chunk[k]` 与 `results[k]` 错位，
  出现"文件名 A、缩略图 B、框是 A 的"。测试里把损坏图放在**中间**（index=1）复现这条。
- 无缺陷图不进 `detection_results`，`检测文件数` 用 `len(set(文件全路径))` 且上传模式该字段恒 `''`
  → **永远是 1**。500 张里 12 张有缺陷，报表写"检测文件数 1"。

**新结构**：

- `results` 长度恒等于本 chunk 文件数，每项带 `index`；失败项 `status=failed` + `error` 原因。
- `file_records` 每个输入文件恰好 1 条：`批次ID / 文件路径 / 组别 / 状态 / 缺陷数 / 模型 / 阈值 / 检测时间 / 备注`。
- Excel：`统计汇总` 全部来自台账（检测文件数、有缺陷、无缺陷、检测失败、失败率、阈值）；
  新增 `文件台账` 页（失败行排最前）。**全干净批次也能出报表**（旧实现直接报"暂无检测结果"）。
- 前端：失败行 `.row-failed` 红色左边界，`applyFilter` 里强制常显（否则被"只显示问题图"规则连坐隐藏）；
  结束提示 `共 N 张：有缺陷 X、无缺陷 Y、失败 Z`，Z>0 走 error toast；历史卡片加 `有失败` 红标。
- 视频侧一并修：`cap.isOpened()` / `VideoWriter.isOpened()` 检查、`frames_failed` 记账、
  状态区分 `done` 与 `done_with_errors`（原来打不开的视频也会走到 `status=done`）。

## 四、#4 复核脚本

新增 `scripts/_review_safe.py`：先把操作记成清单 → 打印 + 落 `_backup/plans/*.csv` →
`--apply` 才执行，执行前逐文件备份到 `_backup/<批次>/`，并增量写 `journal.json`；
`scripts/review_rollback.py --batch <批次> --apply` 逆序还原。

三个脚本的入口统一：`--apply / --batch / --backup-dir / --force / --rollback / --root`。

顺手修掉的三个真问题：

1. `merge_v4_staging` 的 `next_id` 按磁盘 `max+1` 逐次计算 → **同一批里两张负样本会拿到同一个新编号**，
   后一张图片覆盖前一张。改为批次内共享自增计数器（测试断言 `1_0008` / `1_0009` 且内容不同）。
2. `COPY` 的备份只认"目标"，不备份源（否则回滚会把副本又"还原"出来）。这条是写测试时才发现的。
3. `MOVE` 目标已存在时直接 `FileExistsError`，绝不覆盖另一份人工标注。

**注意**：本批只交付"可安全执行"，**没有**对真实母本 `--apply`。`exec_v4_review.py` 当前 dry-run 结果：
A 删除 0 项（`2_0244/2_0417/2_0426/2_0351/9_1334` 早已不在）、B 跳过（`1_0441.json` 不存在）、
