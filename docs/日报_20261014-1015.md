## 一、10月14日：数据集清洗重建 + 系统功能完善

### 1. 母本整理与 V2 数据集三连建
- `问题电芯图片汇总` 全部统一编号（损伤 0_0001~0186 / 暗斑 1_0001~0197 / 亮斑 2_0001~0176 / 负样本 9_0001~0833），清理 109 个孤儿标注，建立重命名对照表
- 新建终版数据集三连：V2 原始版（train 1183 / val 202）、V2_AUG 温和增强版（3773 张）、V2_PP 浓妆版（3773 张）
- 冠军模型在 V2 新考卷基线：mAP50 78.6%

### 2. Web 系统重大修复与新功能
- **修复重大缺陷**：1920 训练的模型此前一直在 640 分辨率下推理（几乎检不出缺陷），已修正为 1920 全分辨率推理
- **智能检测模式上线**：选择母文件夹（如"图片合集"），自动识别 A/B/C… 各组文件夹中的"正面"子目录批量检测，报表按组汇总
- 导出报表新增"组别"列与"分组汇总"工作表
- UI 全面优化：四档响应式布局、下拉箭头去重、窗口自适应对齐、启动自动以应用模式打开 1600×950 窗口
- 置信度默认值调至 0.15（实测黄金点：召回 73%，每图误报 0.2）

### 3. v2mild 模型训练启动
- 温和增强配方（保护微弱斑点），n 模型 1920 分辨率，AutoBatch
- 训练势头显著优于上一版：第 7 轮 mAP50 59.6%（上版同期 47.2%），第 38 轮即达 78.6%（上版 132 轮的终点成绩）
- 833 张负样本压力测试：冠军误报率仅 1.4%，上线不会出现"全是误报"

## 二、10月15日：三模型终对比 + 产线实测定胜负 + 样本量质变

### 1. 浓妆路线实验收尾（证伪，及时止损）
- V2PP 浓妆版训练失败：干净考卷仅 42.1%，同款浓妆考卷补考 78.7%，仍不敌现有模型
- 根因：浓妆预处理在 1920 下噪点淹没微弱缺陷。**浓妆路线正式放弃**

### 2. 数据诚信核查（像素级比对）
- 冠军训练集 vs 现行考卷：**0 张重复**，成绩真实有效
- 冠军旧数据集内部：发现 32 对训练/验证混图，其历史指标有水分（如实记录）
- 发现 CT 相邻切片跨集固有软性泄漏，确立"产线实测为最终裁判"原则

### 3. 产线实测练兵（9620 张实拍图）+ 换岗
- 双模型全量跑测：冠军检出 374 张 / v2mild 检出 238 张，共同检出仅 53 张
- 人工目检裁决：冠军所报损伤大多为误报；**v2mild 实战精确率约 80%，正式上岗**（已设为默认模型 20261014_v2mild）
- 置信度默认阈值上调至 0.30；误报图 370 张收编为负样本

### 4. 工程瘦身
- 形态学提示圈功能下线（产线验证全错），代码与文件彻底清除
- 启动脚本 9 个精简至 3 个；模型库定编并统一"日期_版本"命名

### 5. 产线收割：样本量 12 倍质变
- **385,744 张产线积攒图全量跑完**（阈值 0.5 高置信），收割缺陷候选 6636 张
- 自动生成 X-AnyLabeling 预标注（框已画好，人工只需核对），核对效率提升 5~10 倍
- 确立标注新规：只标电芯主体区域，外围干扰一律不标（已写入标注规范）
