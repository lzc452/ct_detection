# V5.3（带余量 ROI，k=1.5）验收报告

> 冻结 test 676 张 / 442 框 / 170 个缺陷分组。工作点 conf=0.25、IoU=0.50（与产线一致）。
> 权重 `runs/detect/CT_pro/V53_ROI_M15/weights/best.pt`（md5 `f0a4d98dc4f2`）。
> 判据在训练前预注册于 `experiments/FINDINGS.md` F-017。

## 一句话结论

**不通过，四项判据全未达标，触发预注册的"停止 ROI 路线"分支。生产模型继续用 V5（全图@1920）。**

但这一轮不是白跑：它把上一轮（V5.2）造成的损失**全额补回**，并且把"损伤到底卡在哪"这个问题从猜测变成了排除法——现在可以确定**损伤的瓶颈不在数据表示**。

## 一、硬判据

| 判据 | 门槛（= V5 实测） | V5 | V5.2 | **V5.3** | 判定 |
|---|---|---|---|---|---|
| mAP50-95 | > 0.4186 | 0.4186 | 0.3977 | **0.4155** | ✗ 差 0.0031 |
| FP / 千张 | ≤ 88.8 | 88.8 | 131.7 | **110.9** | ✗ 高 25% |
| 组级漏检 | ≤ 26.47%（≤45/170） | 45/170 | 49/170 | **46/170** | ✗ 差 1 组 |
| 损伤召回 | ≥ 0.5616（≥41/73） | 41/73 | 32/73 | **34/73** | ✗ 差 7 个框 |
| 单张推理 | 参考项 | 13.4 ms | 10.4 ms | **9.2 ms** | ✓ −31% |

四项全未过，结论没有解释空间。第三项只差 1 个分组、第一项只差 0.0031，都属噪声量级，但**预注册判据不容事后议价**——"接近"不是"通过"。

## 二、这一轮实际改好了什么

对照 V5.2（同一数据集，只把裁剪窗口从纯 ROI 换成外扩 1.5 倍损伤长边）：

| 指标 | V5.2 | V5.3 | 变化 |
|---|---|---|---|
| mAP50-95 | 0.3977 | 0.4155 | **+0.0178** |
| FP / 千张 | 131.7 | 110.9 | **−20.8** |
| 损伤召回 | 32/73 | 34/73 | +2 框 |
| 组级漏检 | 49/170 | 46/170 | −3 组 |
| 末轮泛化间隙（val−train box） | **+13.1%** | **+1.0%** | −12.1pt |
| 训练时长 | 2.16 h | 2.04 h | −5% |

泛化间隙从 +13.1% 掉到 +1.0%（V5 是 +5.4%），是这一轮最干净的副产品：**窄条视野让模型在第 60 轮左右就开始背训练集，加回周边上下文后这个现象基本消失。** L-012 那条"窄视野导致更早过拟合"的推测得到了直接支持。

## 三、按类别拆开：损失来自哪里、补回了哪里

mAP50-95 是三类 AP 的等权平均，所以 Δ 可以逐位拆解，不用猜：

| 类别 | V5 | V5.2 | **V5.3** | Δ(V5.2−V5) | **Δ(V5.3−V5)** | Δ(V5.3−V5.2) |
|---|---|---|---|---|---|---|
| 极片损伤 | 0.2363 | 0.1813 | **0.1880** | −0.0550 | **−0.0483** | +0.0067 |
| 暗斑 | 0.5326 | 0.4950 | **0.5334** | −0.0377 | **+0.0008** | +0.0385 |
| 亮斑 | 0.4869 | 0.5168 | **0.5251** | +0.0299 | **+0.0382** | +0.0084 |
| 合计 /3 | 0.4186 | 0.3977 | **0.4155** | −0.0209 | **−0.0031** | +0.0178 |

这张表是本轮最有价值的东西：

1. **暗斑完全打平。** 0.5334 vs V5 的 0.5326——差 0.0008，可以忽略。上一轮暗斑掉 0.0377，加回上下文后一分不差地长了回来。**"暗斑的损失来自视野太窄、周边参照物被切掉"这个解释被证实了**（记 F-024）。
2. **亮斑赢得更多。** +0.0302 → +0.0382，说明分辨率增益没被余量吃掉。841×1154 @1536 的缩放率 1.331 仍足以让亮斑达到 22.2px（V5 是 15.1px）。
3. **损伤几乎没动。** 视野从画幅 25.1% 扩到 38.1%（+52% 的相对面积），一个理论上最该救损伤的改动，只换来 +0.0067。**损伤对视野的敏感度是暗斑的 1/6。** 这就把"损伤卡在上下文"这条假设（R2）否掉了。

## 四、损伤 AP 对"数据表示"不敏感——四组独立训练的证据

把所有**未泄漏**的 run 的损伤 AP 排一排：

| run | 数据表示 | 画布 | 损伤 AP |
|---|---|---|---|
| V5 | 全图 2129×1198，缩放 0.90× | 1920 | **0.2363** |
| V5.1 | 全图，缩放 0.99× | 2112 | **0.1647** |
| V5.2 | 纯 ROI 647×991，缩放 1.55× | 1536 | **0.1813** |
| V5.3 | 带余量 ROI 841×1154，缩放 1.33× | 1536 | **0.1880** |
| V5 续训 120 轮 | 全图，同一配方 | 1920 | **0.2213** |

四种裁剪/画布组合、两档分辨率、两个缩放率、两倍训练轮次——**全部落在 0.16~0.24 这个带里，跨度 0.07，且与画布大小、缩放率、视野宽窄都没有单调关系。**

作为对照，泄漏 run 的损伤 AP 是 0.3133（V3）和 0.4091（V4）——明显更高，因为它们的训练集覆盖了冻结 test 的 93.9%。**这证明 0.16~0.24 不是"模型能力上限"，而是"干净考卷上的可达水平"。**

结论（记 F-025）：**继续在预处理侧调画布、裁剪形状、缩放率，损伤 AP 大概率还在带内。** 这不是"再试一次就好了"的问题，是这条路已经走到头了。

## 五、FP 与组级漏检：没有"调阈值就能救"

| conf | V5 FP / 组漏检 | V5.3 FP / 组漏检 |
|---|---|---|
| 0.20 | 106.5 / 24.7% | 130.2 / 25.3% |
| **0.25（产线）** | **88.8 / 26.5%** | **110.9 / 27.1%** |
| 0.30 | 78.4 / 28.8% | 97.6 / 27.1% |
| 0.35 | 68.0 / 33.5% | 90.2 / 28.8% |
| 0.40 | 60.7 / 34.1% | 69.5 / 31.2% |

把 V5.3 的阈值推到能压住 FP（conf≈0.355，FP≈88.8）时，组级漏检约 **28.7%**，而 V5 在工作点就是 26.5%。**两条判据不能同时满足**——这不是工作点选错了，是曲线位置不同。

一个值得记下的细节：conf ≥ 0.30 之后 V5.3 反超（0.35 时 28.8% vs 33.5%）。V5.3 的曲线更"平"，在高精度区更耐压；但产线要的是 conf=0.25 附近，那里 V5 更优。

损伤类的 PR 曲线则是**逐点被支配**：

| conf | V5 损伤 P / R | V5.3 损伤 P / R |
|---|---|---|
| 0.10 | 0.458 / 0.603 | 0.429 / 0.575 |
| 0.20 | 0.575 / 0.575 | 0.500 / 0.493 |
| **0.25** | **0.641 / 0.562** | **0.540 / 0.466** |
| 0.35 | 0.700 / 0.479 | 0.600 / 0.452 |
| 0.40 | 0.702 / 0.452 | 0.660 / 0.452 |

整条曲线 V5 都在右上，不存在"换个阈值 V5.3 更好"的区间。

FP 的来源也指向同一处（V5 → V5.3）：损伤 23→29（+6）、暗斑 27→36（+9）、亮斑 10→10（0）。**全部新增 FP 来自损伤和暗斑两个小目标类。**

## 六、低分辨率桶：加视野完全无效

| 桶 | 张数 | V5 FP/千张 | V5.2 | **V5.3** |
|---|---|---|---|---|
| 高分辨率 2129×1198 | 605 | 87.6 | 125.6 | **104.1** |
| 低分辨率 ~1052×582 | 71 | 98.6 | **197.2** | **197.2** |

高分辨率桶被余量救回了一部分（−17%），**低分辨率桶一位没变（197.2 → 197.2）**。

原因不需要猜：1052×582 的 ROI 只有 319×481，加余量后 415×561，撑到 1536 画布仍是**面积 7.5× 的插值**——源图里本来就没有那些像素，**加视野不等于加信息**。这条结论改变了 P1-2 的做法（记 F-026）：低分辨率需要的是"小图不裁/分桶"，不是继续加余量。

附带一个必须写明的错配：训练集里低分辨率图占 32%，test 只占 11%。低分辨率桶的指标波动大（71 张），单看它容易过度解读。

## 七、判定与后续

**P0-2（带余量裁剪）判定：不通过。** F-017 已按预注册写入"已证伪"，触发第三支——**ROI 路线到此为止**。

理由有两条独立的：
1. 四项判据全未达标；
2. 损伤召回 0.466 < 0.47 的证伪线（虽然只差 0.0038≈0.28 个框，单看这一条属噪声，不构成证据）。

真正有力的是第三条：**损伤对数据表示的敏感度是暗斑的 1/6，且四种表示下 AP 全在 0.16~0.24 带内**。这条不依赖任何贴线的阈值。

### 这意味着什么

损伤占 mAP 权重 1/3，但目前：
- 损伤 AP 0.188 vs 暗斑 0.533 vs 亮斑 0.525 —— 拉低总分的**只有损伤一类**；
- 新增 FP 里 60% 也是损伤和暗斑；
- 而损伤的训练样本只有 **338 框 / 307 图（占训练图 9.6%）/ 129 个电芯，中位每组 2 张**。

**瓶颈已经从工程侧转移到了标注侧。** 表示、画布、轮次、增强这四条都试过了，都在带内；剩下的是"损伤样本够不够、标得准不准"。

### 下一步依赖关系（没有变化）

```
P0-1 标注审计（人力，73 框 ≈1 h/人）── only gates ──→ P1-1 损伤分层采样
                                            ↘ 不 gate
P1-2 分辨率分桶（算力 2.2 h，独立可跑）
```

一个必须先说清楚的算术：**P1-2 单独无法把 FP 拉到 88.8。** 低分辨率 71 张即使完全修好（FP 降到 V5 的 98.6），总 FP 也只从 75 降到 68，FP/千张 100.6，仍高于门槛。FP 的大头在 605 张高分辨率图上（63 个）。所以 P1-2 是"必要但不充分"。

## 八、诚实的局限

1. **损伤只有 73 个 test 框**，召回差 7 个框 ≈ 9.6pt，95% 置信区间约 ±11pt。本报告所有关于损伤的结论都建立在这个样本量上，方向可信、幅度不可精读。
2. **单 seed（seed=0）**。四组 run 方向一致，但没有多 seed 验证，无法排除"这一次恰好运气差"。
3. **by_res 与 workpoint 的 FP 有 ±1 框差异**（损伤 FP 29 vs 30），来自 batch 内不同图片组合导致的 letterbox 差异，属已知的 ±1 噪声，不影响任何结论。
4. **低分辨率桶仅 71 张**，其 197.2 → 197.2 的"完全不变"虽不像抽样波动，但样本小，仍按中等置信度记录。
5. **一次评测只覆盖单一工作点族**（conf 0.05~0.50）。产线若改变工作点，结论需重算。
