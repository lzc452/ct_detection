## 2. #10 修复细节

### 2.1 分组键：三级回退

1. **电芯号（最强）**：从 `重命名对照表.csv` 与 `收割结果_积攒_V4/极片损伤` 的原文件名（`100-10_10073.jpg`）重建，按 MD5 对齐到母本新名。
2. **内容近重复簇**：同一切片的不同副本/重编码副本并入同组。
3. **单图自成一组**。

近重复判据经**阈值标定**确定，不是拍脑袋：

```
cos(64×64 灰度 z-score) >= 0.999  且  MAE(128×128 灰度) <= 1.5
```

标定依据（4592 张全量）：

| 余弦区间 | 对数 | MAE@128 p10/p50/p90 | 判定 |
|---|---|---|---|
| ≥0.9999 | 4589 | 0.03 / 0.07 / 0.13 | 同一张图（含 MD5 相同） |
| 0.9990–0.9999 | 17945 | 0.21 / 0.39 / 0.66 | 同一张图（JPEG 重编码） |
| 0.9950–0.9990 | 43032 | 0.65 / 1.15 / 1.74 | 边界，MAE≤1.5 才合并 |
| 0.9900–0.9950 | 32970 | 1.50 / 2.06 / 3.00 | 不同切片（真实不同切片 MAE≈11.5 @原分辨率） |

> 只用余弦会把"大片均匀背景"的不同电芯误并成巨簇（实测存在 243 张的簇），所以必须叠加 MAE 精筛；只用 MAE 同理会被均匀图骗过。

### 2.2 划分与断言

```
分组：4592 张 → 1284 组（多图组 732，覆盖 4040 张）
train 3195 张 | 负样本 1337 | 框 损伤 338 暗斑 1092 亮斑 630
val    721 张 | 负样本  312 | 框 损伤  73 暗斑  234 亮斑 136
test   676 张 | 负样本  287 | 框 损伤  73 暗斑  234 亮斑 135
```

三方断言（`--mae 1.5`）：

| 校验 | 结果 |
|---|---|
| 组键跨集 | 0 |
| MD5 跨集 | 0 |
| 像素级近重复跨集（train×val / train×test / val×test） | **0 / 0 / 0**，高余弦对也为 0 |

**Before / After（同一判据）**

| 划分 | val（或 test）中含"train 里有像素级重复副本"的图 |
|---|---|
| 旧 `CT_DATASET_FINAL_V4` | 535 / 642 = **83.3%** |
| 新冻结划分 | 0 / 676 = **0%** |

### 2.3 必须披露的缺口：电芯号只有 4.1%

| 项 | 数值 |
|---|---|
| 能重建电芯号的图片 | 189 / 4592 = **4.1%**（重命名对照表 189 行 + 收割结果 186 个原名） |
| 其余 95.9% | 母本已扁平重命名（`0_0001.jpg`），原始 `批次/电芯/视角/切片` 层级不可恢复 |

后果（写进结论里，不藏着）：
- 现在的分组等于是"**像素级重复隔离**"，不是严格的"**同一电芯隔离**"。
- 同一电芯的**相邻切片**仍可能一train一test（不同切片 MAE≈11.5，不会被聚到一组）。这类泄漏比"同图重复"轻，但对极片损伤这类贯穿性缺陷仍有乐观偏差。
- 要升级为真正电芯级隔离，需要业务侧提供 `电芯编码 → 母本新名` 的完整映射（重命名对照表只覆盖最后一轮入库），或后续入库时把电芯号写进文件名/清单。这属于**数据侧动作，需你确认后再做**。

## 5. 泄漏到底吹高了多少（2026-10-21 追加实测）

### 5.1 冻结 test 对 V4 的污染是 93.9%，不是 82.3%

```
冻结 test 676 张：
  与 CT_DATASET_FINAL_V4/train 字节相同（md5）        555 张
  另有仅靠"像素近重复"命中（cos>=0.999 且 MAE<=1.5）   80 张
  ──────────────────────────────────────────────────
  合计 V4 训练时"见过"                              635 张 = 93.9%
  真正没见过                                          41 张 =  6.1%
```

之前只算 md5 得到 82.3%，加上近重复判据后是 **93.9%**——即这份"新考卷"对 V4 而言几乎还是旧考卷。

### 5.2 seen / unseen 拆分实测（`scripts/eval_seen_unseen.py`）

| 模型 | 子集 | 张数 | mAP50 | mAP50-95 | 损伤 R@IoU0.5 |
|---|---|---|---|---|---|
| V4 | seen（训练见过） | 635 | **0.907** | **0.571** | 0.667 |
| V4 | unseen（没见过） | 41 | 0.722 | 0.422 | 0.880 |
| V5 | seen | 635 | 0.762 | 0.408 | 0.438 |
| V5 | unseen | 41 | 0.709 | 0.356 | 0.800 |

**方向性结论**：V4 从"见过的 635 张"到"没见过的 41 张"，mAP50 **−18.5pt**、mAP50-95 **−14.9pt**；同一批图上 V5 只掉 5.3pt / 5.2pt。V4 的高分有相当部分来自背题。

**必须同时说明的局限（否则就是过度解读）**：

- unseen 只有 41 张，且类别构成严重偏斜——损伤框 25 个，而暗斑仅 8 个、亮斑 13 个（全集是 73/234/135）。所以 unseen 那一列里"暗斑 AP50 从 0.941 掉到 0.521"**不能**当作结论，那是 8 个框算出来的。
- 因此上表只能作为**泄漏存在的方向性证据**，不能作为"泄漏精确值 = 14.9pt"的定量结论。
- 要拿到无争议的泛化数字，唯一办法是**用新划分 + 与 V4 相当的训练预算重训**，且测试集里不能再混入训练见过的图。

### 5.3 V5 的数字为什么低（三个混淆因子必须分开看）

| 因子 | V4 | V5（80ep） | 影响 |
|---|---|---|---|
| 训练集图片 | 27 606（AUG 版）/ 3 753（原图版） | **3 195** | 数据量差 1.2~8.6 倍 |
| epoch | 300 配置，第 75 轮早停 | **80（跑满，仍在升）** | 梯度信号约 1/4 |
| 测试集是否训过 | **93.9% 训过** | **0%** | 决定性 |

**修正（2026-10-21 20:26，续训实测后）**：原文此处写"V5 是被预算截断的，不是收敛的"，**该判断已被续训实验证伪**。从 best.pt 低 lr 续训 120 轮（lr0 3e-4、patience 30）在第 29 轮达到最优、第 59 轮早停，test 上 mAP50-95 从 0.4186 → 0.4165（**−0.0021**），远小于 val 单点噪声 ±0.0097。结论：**V5 在 80 epoch 时已收敛，预算不是瓶颈**。

因此 V5 的 `mAP50 0.803 / mAP50-95 0.419` 不是"下界"，而是**当前数据与模型容量下的真实性能**。要再往上走，必须改**数据或预处理**，加 epoch 无效（详见 `docs/preprocess_analysis_20261021.md` 与 §7.6）。

| 项 | 值 |

> 注意：本次续训**不恢复优化器状态**（从 best.pt 当预训练权重起新 run），因此它是"低 lr 微调 + 重新退火"，不是断点续训。这一点写进 `_train_meta.json` 的 `resume_from` 字段，避免以后误读。

#### 续训结果（2026-10-21 20:21 完成，结论：**无收益**）

| 项 | 值 |
|---|---|
| 轮次 | **第 29 轮达最优，第 59 轮触发早停**（patience 30），总耗时 2.40 h（146 s/轮） |
| 最优 val | mAP50 = epoch 37（0.7829，P 0.862 / R 0.759）；mAP50-95 = epoch 29（**0.4154**） |
| 对比 80ep 起点 | val mAP50-95 **+0.0015**、mAP50 +0.0075 |
| **冻结 test** | mAP50 **0.7787** / mAP50-95 **0.4165** → 相对 80ep 为 **−0.0241 / −0.0021** |
| val 单点噪声 | 全 59 轮 mAP50-95 标准差 **0.0097**，故 −0.0021 完全在噪声内 |
| FP/千张 / 组级漏检 | 85.8（←88.8）/ 28.8%（←26.5%），均无实质改善 |

**这推翻了我原先的判断。** 原假设"V5 被预算截断，续训能涨"，实测证伪：从第 5 轮起 mAP50-95 就爬到 0.397，之后 54 轮一直在 0.395~0.415 的噪声带里震荡，29 轮触顶后不再前进。**V5 在 80 epoch 时已经收敛**，学习率降到 3e-4 也打不开新的解空间。

因此 §5.3 的"下界"说法已修正：`mAP50 0.803 / mAP50-95 0.419` 就是**当前数据 + yolov8n + 1920 方形画布下的真实性能**，加 epoch 无效。要提升只能动**数据/预处理/模型容量**。

原三个候选里，**B（补齐 V4 级预算 2.7 万张 / 300ep）现在也可以判为无效**——预算已被证明不是约束；除非那 2.7 万张是"新的真实数据"而非离线增强副本。
